# Perfiles de tareas de usuario utilizando Ionic Angular y JSON API

## Frontend con Ionic Angular

1.- Para crear una tarea de usuario, nos dirigimos a la página de inicio. Una vez que estemos en la página de Inicio, hacemos clic en **Nuevo**. En esta página encontramos las tareas que estan curso y luego se encuentra en la parte de abajo las tareas completadas.

![image](https://github.com/user-attachments/assets/041ef780-1a56-4d01-bae4-beedf9f10e86)

2.- En la opción de **Nuevo**, nos encontramos con la ventana de una lista de tareas, para crear una nueva tarea, le damos clic al Icono de **Añadir tarea**

![image](https://github.com/user-attachments/assets/a4dcd74b-3ab0-4f98-a526-f0f8dddd0bc7)

3.- En la opción de **Añadir tarea**, ingresamos el título y la descripción de la tarea, una vez hecho eso damos clic en **Guardar tarea**

![image](https://github.com/user-attachments/assets/ddce8579-cd91-4dc2-8a44-1b18f335a2fd)

4.- Una vez creada la tarea, la visualizamos en la actualización de **Mis tareas**

![image](https://github.com/user-attachments/assets/1e7e90b0-8271-4d79-aa4b-502eaf0ab99e)

5.- Damos clic en la opción de **Atrás** para ir a la página principal de **Home**

![image](https://github.com/user-attachments/assets/735fdf5f-293b-417c-af7c-04b0f34dd51a)

6.- Para culminar una tarea, hacemos check en la tarea creada, la damos por finalizada, se debe visualizar en **Terminados**

![image](https://github.com/user-attachments/assets/562e0495-6044-4e0f-b19c-950bb4a8724c)

7.- Una vez hecho el proceso, se visualiza la tarea finalizada

![image](https://github.com/user-attachments/assets/c4a6b541-39f3-4b4f-bbc2-2433f70ecbab)

8.- Para cerrar sesión nos dirigimos al ícono de **Menú** y automáticamente se despliega el nombre del usuario logueado y las diferentes acciones que se quieren hacer.

![image](https://github.com/user-attachments/assets/49273d48-6624-4034-b1e0-8d0b44297c7b)

* Si queremos cerrar la sesión hacemos clic en **Cerrar sesión**
  
![image](https://github.com/user-attachments/assets/67928898-c08e-45a4-a76c-79135a00b1af)

* Si queremos continuar con la sesión hacemos clic en **Cancelar**
  
![image](https://github.com/user-attachments/assets/eb6b8584-4cf5-4628-8bca-b28741390673)
